# cimbar-js-bits

Generated WebView assets for `turtleSST/cfc`.

The `2026-08-01T1335` bundle is built from `turtleSST/libcimbar` commit
`4c5dafb6479d8c0a1f8e44c67dce795c88d07e4a` and includes the Fountain v2 encoder/decoder
bindings. The bundle is split into `index.html`, JavaScript, and WASM files
so it can be consumed by the Android WebView build.
